Privacy policy

Last updated: 20 November 2026

What the app accesses

When the channel owner connects a YouTube channel, Itihas Studio uses Google OAuth with read-only scopes (youtube.readonly and yt-analytics.readonly) to read that channel's details, its list of uploaded videos with public statistics, and YouTube Analytics reports (for example views, watch time and audience retention).

How the data is used

The data is shown only to the channel owner, in a dashboard running on the owner's own computer, to review how videos perform and plan new ones. It is not used for advertising.

Storage

OAuth tokens and fetched reports are stored only on the owner's computer. Nothing is stored on any external server operated by the app.

Sharing

The data is not sold, shared, or transferred to any third party.

Google API Services User Data Policy

Itihas Studio's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be removed at any time from Google Account → Third-party connections, or with the app's Disconnect button, which deletes the stored token.
